读数与现场使用说明

节目响度使用 ITU-R BS.1770-5 的 K 计权和 EBU R128 门限算法，支持单声道与立体声。M 为 400 ms，S 为 3 s；I 使用 −70 LUFS 绝对门限和 −10 LU 相对门限；LRA 使用短时分布的 10–95 百分位。−23 LUFS 是 R128 节目参考值，不是演出现场声压目标。

点击“暂停累计”可保持实时观察，同时暂停 I、LRA、最大值与真峰值统计；继续后分别等待完整 400 ms / 3 s 窗口再计入。首次 400 ms / 3 s 尚无 M / S 值；LRA 在短片段中可能不稳定。算法通过合成信号回归核对，未取得仪表认证。

Leq 是整个有效测量时段的声能平均；SEL 是累计声能折算到 1 秒的声暴露级，时长增加时可能持续上升。声级与节目响度各自累计；校准只影响现场声级读数，不改变 LUFS 或 dBTP。

A/C 为频域近似计权，Fast/Slow 为分块指数响应；频谱为不计权的近似三分之一倍频程，低频受分析分辨率限制。这是现场声音分布，并非音箱或场地的传递频响。

校准后仍为估算：内置麦克风的频率响应、增益处理和大音量失真会影响读数；一次声级校准不能修正频响。出现削波或自动增益提示时，应调整位置并用参考仪表复核，不能用此工具判断听力安全或替代合规声级计。

保持页面前台和屏幕点亮。离开页面、锁屏或麦克风中断会停止本次测量；保留最近一次显示结果，可导出。界面约每 85–93 ms 刷新一次，停表末尾不足一次刷新的数据不计入保留结果。重新开始会清空旧结果。输出采集通过系统共享选择器授权；页面只分析音轨，不读取画面、不录制、不上传。输出数字电平与扬声器实际声压不同，不能校准成 dB SPL。
