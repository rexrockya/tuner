# BopLand guitar harmony index

`guitar-index.js` is an unmodified snapshot retrieved 2026-09-08 from
https://bopland.org/data/guitar-licks.js?t=1335 .

Source: BopLand.org guitar lick database (2,525 entries), licensed under
Creative Commons Attribution-ShareAlike 4.0:
https://bopland.org/terms-of-use and https://creativecommons.org/licenses/by-sa/4.0/ .

This local copy makes harmony search independent of the metadata server. Score
images and demonstration MP3s are still served by BopLand and require a network
connection. Attribution is displayed below the library player. Browser-generated
original exercises live separately and are not represented as BopLand recordings.
