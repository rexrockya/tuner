# 弦音：照片 / PDF 自动识谱方案

日期：2026-09-06。方案待确认；没有开通服务器、付费订阅或商业授权。

## 已完成与边界

- 手机工具栏：整组换行，按钮不压缩，44px 点击区域。
- 节拍器与乐器独立音量；修改音量不改变播放时间轴。
- 乐谱 Library → 录入乐谱 → 拍照 / 选择图片或 PDF → 预览、调整文件顺序、移除。
- 当前仅保存本机临时草稿，不是账号云存储，不上传、不识别、不自动加入可播放曲库。浏览器清理数据后草稿可能丢失。
- 原有塞茨谱保留“待校对”提示，不视为正确答案或识别成功样本。

## 推荐：先验收识别效果，再购买服务

先用用户提供的约 10 页有代表性的原稿进行小规模测试：清晰 PDF、手机拍照、小提琴单声部、钢琴双谱表、附点、连音线、弱起、反复记号。不要仅凭“能导出 MusicXML”判定成功。

成本参考：Hetzner 官方表列 CX33 新价格 €8.49/月，不含 VAT 与 IPv4；产品页规格为 4 vCPU / 8GB，但查询时标记缺货。仅用于说明基础计算成本量级，不是可立即购买的承诺，也不是人民币换算报价。亚洲地区服务器、备份、网络和存储可能增加成本。[官方价格](https://docs.hetzner.com/general/infrastructure-and-availability/price-adjustment/)、[规格与库存](https://www.hetzner.com/cloud/cost-optimized/)。

Audiveris 提供批处理和 MusicXML 导出，集成时需核实并遵守其开源许可。[官方 CLI](https://audiveris.github.io/audiveris/_pages/guides/advanced/cli/)、[项目仓库](https://github.com/Audiveris/audiveris)。

ReadScoreLib 是 PlayScore 使用的识谱引擎，有 SDK 授权；服务器运行平台及授权范围需向厂商确认，不假设它已有可直接调用的公有云接口。[PlayScore 官方说明](https://www.playscore.co/windows-help/)。

不建议为了接入网站自动识谱而直接购买 Soundslice 订阅：其官方文档明确说图片 / PDF 扫描没有 API；其一般数据 API 不能替代扫描接口。[Soundslice 官方 API 文档](https://www.soundslice.com/help/data-api/#upload-a-slices-notation)。

## 接入后的使用流程（尚未实现）

手机登录 → 录入乐谱 → 拍照 / 上传 → 预览与裁切、确认页序 → 提交识别 → 等待结果。

- **通过**：在账号私人曲库保存原稿、MusicXML、音符时间轴和校验报告；打开即可使用现有音色与固定 BPM 节拍器。
- **待校对**：保留识别结果和原稿，指出可疑小节；不自动标为正式谱。格式与拍数正确也不等于音高完全正确。
- **失败**：明确给出“图片不清晰 / 文件损坏 / 不支持的谱型 / 超时”等原因，可重拍、重传或重试；不写入正式曲库。
- 第一阶段给站内状态与通知；离开页面后回来仍能查询任务。系统推送另需用户授权，不默认申请。

## 技术边界与验收

- 公开入口仍仅为 `https://rexrockya.github.io/tuner/`。
- 在已有账号服务后增加鉴权任务接口、队列及识谱计算服务；D1 保存归属、状态与结果索引，R2 保存原件和 MusicXML。账号之间严格隔离，不公开上传的谱子。
- 前端可直接调用现有 API 网关，但不暴露服务密钥；手机不需要安装 Java，不把完整识谱引擎塞入页面。
- 文件类型和真实内容双重检查，限制大小、PDF 页数和像素总量；解压 / PDF 处理置于隔离进程，设置 CPU、内存和超时限制。失败重试有限次，避免费用无限增长。
- 状态：queued → processing → passed / needs_review / failed；提交幂等，刷新页面不重复计费；提供删除原件及任务入口。
- 解析 MusicXML 后检查每个声部、拍号、每小节总时值、弱起、跨小节延音、三连音、反复与速度标记。节拍器使用固定 BPM，不从识别出的音符数量推算拍速。
- 验收必须比较原谱与结果的音高、时值、升降号、声部归属，并实测播放。首轮人工验收用来确定自动放行条件；不预先宣称识别准确率。
- 建议试点限每份 10 页、每账号单任务并发，并设置月度总页数 / 费用上限；具体限额待用户确认。
