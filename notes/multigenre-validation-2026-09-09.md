# 多风格教学与 Funk 音色验收

实现于独立工作区 `TUner-genres`，基于 a932fc1。原 main 目录同时进行另一任务的演奏功能开发，未改动其未提交文件。

## 交付范围

- Blues、Jazz、Funk / Soul、Shoegaze、Folk、R&B 统一风格入口。
- 21 个原创分级课程，Funk 6 课中 3 课专练节奏吉他；来源在 genre-curriculum.js 中。课程任务不等同于随机生成器逐项执行的标准答案。
- 各风格独立和声预设、旋律生成、密度、自动配器及默认音色；现有 TAB/实音高五线谱、变调、变速、小节循环、音色/音量、主奏 MIDI 和收藏继续使用。
- Funk 十六分短切 / Soul 应答实际事件绘谱、模拟闷击、播放格跟随与吉他静音跟练。旧型中非十六分格的收尾不显示为该练习谱。
- 原创电子鼓 8 个 WAV，全部单声道 44100 Hz PCM16，220852 B；最高峰值 0.75998。生成脚本/校验脚本/逐文件 SHA256 与来源说明随资源交付。
- 两种实时 Synth Bass、两种 Synth Keys；短奏/空间吉他为电吉他采样处理。没有调用 Suno、没有新增真人木吉他采样。

## 验证

- `music-genres.cjs`：2520 个确定性旋律案例；六风格及动机/切分输出实质不同；音符/指法/和弦边界；所有新旧律动与声部型；独立静音不重写 Bass；九音色彩与旧 intervals 兼容。
- `genre-controls.cjs`：六选择器/21课、模式切换、各风格精确草稿、跨风格与旧收藏、MIDI、节奏格、静音吉他、完成/收藏、资料库保持。
- `practice-timbres.mjs`：电子鼓不加入初始 preload，共享请求/缓存、实际 WAV 调度；两层 synth 与停止；空间音色自然尾声保留及暂停清理。
- `feature-loading.cjs`：新模块顺序、重复进入去重、加载时离开后不重新打开、无自动麦克风采集。
- 原有完整 `npm test` 已通过；修复审查问题后再跑相关生成、UI、音频与绝对时钟回归。
- 首屏预算在本次增加后仍低于 120000 gzip6 B；大部分新教学与规则按需载入。

这是代码、事件、资源及音频图验证，不是实体手机主观试听或浏览器画面验收。未新增浏览器 UI 测试。
