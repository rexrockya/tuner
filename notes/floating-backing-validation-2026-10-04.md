# 悬浮生成伴奏验收 · 2026-10-04

## 范围

以 LcAoWGYi 指板为主要用例，将教学原有伴奏入口改为共享悬浮播放器。保持原曲 MP3、原谱图片、合成音高核对和生成伴奏各自含义明确。仅修改原 GitHub Pages `docs/`，无 Worker/Sites 部署、无新第三方依赖。

## 实现

- 当前页面和声直接开始，BPM 40–180、六种曲风、12 个移调主音；保留小调性质、斜杠低音及全部和弦色彩。
- 原有鼓、Bass、键盘、节奏吉他、辅助打击、弦乐的演奏方式、真实录音音色、音量保留在折叠控制内。
- 最小化不中断，关闭停止；页面隐藏、换课、来源播放会取消等待中的音源准备和未来排程。
- 初始资源按需载入；主站首次资源 gzip6 118,271 / 120,000 字节，21 项，预算测试通过。
- 每个 Transport 管理自己的声音作用域，停止时也清理先前 live-edit 留下的尾音；闲置实例不会静音其他实例。
- live 设置先准备音源，下一安全小节线生效。未提交设置与当前可听设置隔离，连续输入以后者为准。音量变动不会被较早的异步候选覆盖。
- 移调指板为同调和弦地图，不把固定原谱的弦/品/音符伪装成移调结果；回原调恢复原逐音数据。跟随默认关闭。
- LcAoWGYi 为 C 调、4/4，三小节 Dm7 → G7 → Cmaj7（BopLand 裸 maj 按其来源约定为 maj7）。没有经验证的原始逐音或换和弦时刻；生成节奏明确独立于原始示范。
- 目前仅启用 4/4。源为 3/4、5/4 时明确说明限制，不悄悄改写拍号。独立自定和声仍为 4/4。
