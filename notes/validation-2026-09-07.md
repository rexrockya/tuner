# 2026-09-07 家庭练琴版验证记录

本文件记录发布前校验及验证边界。公开交付只使用 https://rexrockya.github.io/tuner/ 。

## 自动校验范围

- `npm run build:scores`：生成 13 首懒加载谱和同步内嵌目录；第一张图保留 35 小节完整校对版。
- `npm test`：页面五大入口、唯一 ID、标签及引用、脚本语法、本地资源；教学筛选/切换/收藏/A-B 循环/速度/音阶；13 首资源一致性；分类、搜索和收藏；旧谱链接降级；音色切换；三分钟稳定拍点和 48 次循环无累计漂移；暂停/跳转/双音量/拍号；全部音符直到末小节。
- 实际 OSMD 库在模拟 DOM 中渲染：35 个小节目标，375/844 像素适宽、0.5–4 倍缩放，位置不变，小节双轴跟随。库来自本机已缓存固定版本，无需新增外部服务。
- `npm --prefix website run lint` 与 `npm --prefix website test`：后台代码检查、构建和真实 Worker HTML 响应。旧测试错误地要求已删除的初始化骨架，已改成真实调音/房间页面、隐私文字和正式前端边界断言。

## 本轮修补

- 删除用户指定的独立旧协奏曲数据；旧链接不再误开目录第一首。
- 移除无效录入入口、弹窗、脚本及样式。没有清除浏览器原稿数据库，没有建立或声称有云同步。
- 钢琴按广义“古典 / 拉格泰姆”分组；搜索和收藏不会让曲子从分类中消失。
- 从小提琴切换钢琴曲恢复钢琴音色；同一首曲子切换标签页保留当前选择。
- 扩展一键测试入口，修正教学测试的过时 DOM 断言和异步清理时序。

## 未验证与限制

- 已尝试两次通过浏览器工具复用现有网页标签；两次均在选择标签阶段超时。因此**未完成真实浏览器点击/截图验收**，模拟 DOM 不能等同于实体手机测试。
- 未录制麦克风输入、未做真人音色听感判断；未用真实账号提交登录/注册、未授权 Flat、未创建云端 Jam 测试记录。
- 第一张乐谱仍有公开标注的编辑性修补和待校对小节，未声称转录完全正确。
- 原图/PDF的跨设备保存和自动处理队列延期，不建立收费识谱服务。
