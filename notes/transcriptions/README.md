# 第一张上传谱：整页可播放校对版

2026-09-07 替换开头节选。输入 `violin-upload-2026-09-06-1.json` 是逐小节人工辅助转录，生成器为 `scripts/build-uploaded-violin.mjs`，通过 `npm run build:scores` 生成网站使用的 MusicXML、MIDI、音符时间表与目录。

覆盖图片全部10行：第1行对应1–8小节（前6小节休止），第2行9–11，第3行12–14，第4行15–17，第5行18–20，第6行21–23，第7行24–26，第8行27–29，第9行30–32，第10行33–35。原图的行首数字有跳跃，网站按可见小节线连续编号，华彩排为30、31两小节。

这是**整页可播放校对版**，不是已经过音乐教师确认的原书重刻。所有行都进入播放时间轴，但仍有以下明确的编辑处理：

- 第18小节图中可见时值只有3.5拍。末尾添加半拍休止，MusicXML 用橙色休止和“校补”文字标记，manifest 保留 `editorialCorrections`。不声称此休止来自原书。
- 第25小节的临时升号暂记 B♯4；第32小节第三拍按八分＋十六分＋十六分休止处理。均在谱内标出重点复核提示。
- 第32、33小节持续 A4 半音符与活动声部分开，用 MusicXML voice/backup 保存，不把持续音反复触发。
- 第11小节颤音以C♯5/D5交替试听，末尾B4/C♯5小音符各占主音最后1/8拍；第31小节A3小音符占后续主音最前1/8拍。这是固定速度练习用的装饰音分配，不是唯一的演奏解释。
- 第30小节六连音每音1/6拍；其他三连音按1/6或1/3拍区分。华彩、rit.和延长记号保留谱面标记，播放不自动变速，沿用用户要求的稳定节拍。
- 没有完整复刻全部指法、弓法和动态力度。原图有生成水印和变形符号，仍须对照原书校对音高与记号。

格式实现参考：[MusicXML grace](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/grace/)、[多声部 backup](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/backup/)、[连音 time-modification](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/time-modification/)。

验证包括全部35小节每声部时值、10行覆盖、276次发音、140个固定间隔节拍、两处多声部、三枚小装饰音、六连音、最终结束时间、MIDI事件数，以及实际OSMD渲染。默认从第7小节开始，点击“回到开头”仍可播放包含6小节休止的完整时间轴。
