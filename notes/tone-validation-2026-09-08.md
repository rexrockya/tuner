# 小提琴、现代吉他与厚实电贝斯验收 — 2026-09-08

## 交付

创作Lead小提琴不再依赖固定的不足音量系数，而按各实际音高录音计算有限静态补偿。窗口.08–.6秒、双声道平均能量、目标-24dBFS RMS、增益最多8倍、整段峰值最高-6dBFS。保留音符力度差、原录音与乐谱播放器；短热样本/窗口外峰值仍受保护，静音不放大。分析只在采样进入缓存时执行，不加入音频调度循环。

Lead与节奏吉他的暖净音、亮净音、厚过载保留warm/bright/crunch兼容ID，升级高低频整理、宽带低中频、轻饱和和每音柔和压缩，使用原24个真实Shinyguitar采样。按离线输出重新配平三个音色的trim，主压缩器参数不变，之后增加.84固定输出余量（约-1.51dB）。

Bass新增「P 风格 · 厚实指弹」，在音色与音量中的Bass下拉选择。采用16条CC0 Swagbass录音：8个根音、每根2次真实演奏，f单力度层；每对共享增益、4秒和120ms尾渐弱、44.1kHz单声道16bit。实际源琴是Ibanez BTB-400QM颈拾音器和平绕弦；P表示本站声音方向，不声称Fender实采或品牌背书。原3种Bass继续提供，默认仍round。

新的1,366,183字节FLAC库只在选择P风格且计划含Bass时下载，另有5,646,048字节WAV回退。首次准备、并发、慢资源/失败、重试、小节线提交、旧请求取消均保留连续播放逻辑。所有滤波、饱和、压缩节点结束或候选取消时释放。许可原文、作者README、固定提交及逐文件hash保留在现代Bass目录。

- 全88个实际小提琴MP3解码，按生产的双声道能量算法检查；常用MIDI48–84全部达到归一目标，整体峰值仍有余量，11个极低音触及8倍上限而不继续抬高。逐音原始/校准后数据见`tone-violin-levels-2026-09-08.json`；这里是采样电平，最终混音另测。
- `practice-tone-balance.mjs`真实sample bank检查RMS与窗口、跨声道平均、8倍上限、窗口外峰值/短源/零源、每声道只测一次、并发缓存、原PCM及钢琴不变。
- `practice-modern-bass.cjs`9组检查16录音/哈希/WAV规格/尾渐弱与两次录音确实不同、nearest根音/rate/variant、默认零新请求、按需并发共享、FLAC解码失败WAV回退、部分失败复用15缓存、停止失败回退、播放中旧音延续/边界提交、候选未来首拍取消和全部效果节点释放。
- 最终完整`npm test`通过：新旧和声输入、8064强度组合、编配、音源与连续时钟/控制/收藏/MIDI、真实OSMD乐谱、存储/加载/导航/性能、调音器及46项响度标准信号。首次运行有未修改生成器在Node VM中的Math.abs偶发异常，单独与最终完整重跑均通过，未改生成逻辑。

### 最终离线音频

使用node-web-audio-api OfflineAudioContext执行实际音源、生产处理图与调度代码，原版基准为4abdac2，最终源码raw及LF哈希已分别核对当前文件。报告见`tone-offline-before-2026-09-08.json`和`tone-offline-final-2026-09-08.json`。23个固定输入全部0个越界采样，最高采样峰值-1.1508dBFS（挑战档、180BPM、所有轨100%）；这只约束已测案例。

| 同力度Lead、单轨100% | 最终active RMS dBFS |
| --- | ---: |
| 暖净音 | -25.803 |
| 亮净音 | -26.349 |
| 厚过载 | -24.805 |
| 小提琴 | -27.365 |
| 钢琴 | -21.288 |

固定7音小提琴较旧版提升13.01dB，与暖净音吉他差距由约14dB缩为1.56dB。这里是该测试片段的RMS，不是承诺所有乐句固定增幅。

工具库的未来setTargetAtTime原生实现存在数值异常，故适配器把已使用的setValue/linearRamp/setTarget包络转换为逐样本解析曲线，其他真实节点与音源不变；88200采样的独立ConstantSource验证最大误差1.49e-8。源码与重现步骤在`tests/qa/audio/`，测试依赖和WAV/缓存写TEMP，不加入网页或常规npm test依赖。此验证不是浏览器实机音频，也不是对全部WebAudio自动化行为的替代实现。

## 验证边界

没有控制浏览器或进行真实手机、耳机、蓝牙/扬声器的主观试听。离线工具执行实际源码、真实PCM与处理图，固定乐句只用于比较电平与选定压力输入的峰值，不等于认证响度测量或每种输入都不会削顶。主观是否符合用户的“现代、饱满、P Bass”需要用户在实际设备确认。Fender不是本音源品牌；仅f单力度层，不能声明P Bass实采或多力度源库。
