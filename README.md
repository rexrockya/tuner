# 弦音 Tuner

一个为 Android 手机设计的开源乐器调音器，同时提供可直接使用的网页版。

## 功能

- 实时麦克风音高检测
- 音名、频率与音分偏差显示
- 吉他、尤克里里、小提琴和十二平均律模式
- Android A4 基准可在 430–450 Hz 调整；网页版提供 440 / 441 Hz 与标准音播放
- 教学包含乐句检索、原创练习句与 Blues 伴奏
- 按级数（2-5-1）或和弦名筛选 2,545 条乐句（BopLand 2,525 ＋ GuitarSet 20），支持跨调与来源筛选
- 浏览器按和声生成 6 类原创吉他乐句，支持默认六线谱／整页实音高五线谱切换、试听、本机收藏和 MIDI 导出
- 温暖的真实拱面吉他采样、独立节奏吉他、鼓与电贝斯采样、合成风琴；8 类律动、6 类 Bassline 与按乐段随机变化
- 鼓、风琴、节奏吉他分别选择演奏风格并在整轮收尾加入 fill；风琴/节奏吉他支持 None
- 音色与音量一处控制，每轨三种音色；Lead 可选三种吉他、大钢琴或小提琴，切换保留位置并暂停
- 乐句示范音频、波形与 A/B 循环，换句恢复原速；伴奏可点选小节、变速和单节循环
- 本地记录课程完成状态
- 原生 Android 应用，支持 Android 8.0 及以上

## Android 构建

```powershell
./gradlew.bat assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 网站

正式网页：https://rexrockya.github.io/tuner/

`docs/` 是 GitHub Pages 的完整静态前端（调音、教学、分类乐谱、节拍器、Jam）。`website/` 是可选 Worker 实现，不要用其构建结果覆盖 `docs/`。

乐谱维护及前端测试：

```powershell
npm run build:scores
npm test
```

产品范围见 [PRD.md](PRD.md)，维护与发布见 [HANDOFF.md](HANDOFF.md)。目前无网页图片上传/自动识谱服务；家人可直接提交谱图附件进行异步转录。

可选 Worker 本地开发：

```powershell
cd website
npm install
npm run dev
```

## 隐私

麦克风音频仅在设备本地实时分析，不录音、不上传。

## 手机现场响度表

在原站点选择「工具 → 响度表」，允许使用麦克风。默认节目响度采用 ITU-R BS.1770-5 / EBU R128 的单声道/立体声算法，显示 M、S、累计 I、LRA 和真峰值 dBTP，可暂停/继续累计。频谱与最近 120 秒响度使用轻量曲线。切换“现场声级”支持 A/C/Z（A/C 为频域近似）、Fast/Slow、累计 Leq、SEL、最大响应值、Z 采样峰值、近似三分之一倍频程频谱和 CSV 导出。
未校准显示 dBFS；与参考声级计对照校准后才显示估算 dB SPL。校准仅对本次输入会话有效。
页面转入后台或输入中断时停止采集并保留结果。浏览器未必能关闭手机全部音频处理，且内置麦克风可能在演出声压下失真；不能替代专业声级计，也不能仅凭频谱判断场地传递频响。

电脑端可选麦克风设备，或通过浏览器共享选择器采集标签页/系统音轨；输出音频支持 LUFS / dBTP 与数字电平，不能做 SPL 校准。手机端按浏览器能力显示「手机输出」，不支持时禁用并说明原因，不会自动改用麦克风。调音与节拍也统一位于工具页。


网页版调音器采用音高环空闲界面，不再显示粗白条。可播放 A4 标准音并切换 440 / 441 Hz；手动进入“声音时间轴”后采集生活中的单音，显示音高轨迹和音名。时间轴不自动启动、不会录音，支持暂停画面和清空。

新音源为 Karoryfer Shinyguitar 的 CC0 采样；新增乐句来自 GuitarSet v1.1.0（CC BY 4.0），谱面按原始演奏标注生成并非人工认证转录。详见资源目录中的许可与来源记录。本轮验证与设备边界见 [音乐工具验收](notes/music-tools-validation-2026-09-08.md)。

新版伴奏风格、音色和五线谱维护与验证见 [组合练习验收](notes/ensemble-validation-2026-09-08.md)。多种鼓/Bass/吉他音色是现有真实录音的处理变体，钢琴和小提琴复用乐谱音源。五线谱使用实际音高，Swing仍按直写节奏演奏。
