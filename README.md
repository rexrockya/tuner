# 弦音 Tuner

一个为 Android 手机设计的开源乐器调音器，同时提供可直接使用的网页版。

## 功能

- 实时麦克风音高检测
- 音名、频率与音分偏差显示
- 吉他、尤克里里、小提琴和十二平均律模式
- Android A4 基准可在 430–450 Hz 调整；网页版提供 440 / 441 Hz 与标准音播放
- 教学支持 Blues、Jazz、Funk / Soul、Shoegaze、Folk、R&B：统一风格选择，21 个分级原创练习，以及独立乐句资料库、原创与伴奏模式
- Funk / Soul 含 6 课，其中 3 课专练节奏吉他；十六分短切／Soul 应答显示随播放移动的节奏格，支持静音吉他自己弹
- 每种风格有专用旋律规则、和声预设与自动配器；分别保存原创／伴奏草稿，保留密度、跟谱、小节循环、收藏与主奏 MIDI 导出
- 新增按需加载的原创合成鼓（Kick、Snare、Hat、Ride）、两种 Synth Bass、两种 Synth Keys，以及干净短奏／空间延音电吉他音色
- 和声以数字输入：逗号分小节，支持 b7、#4、1maj7、57、4sus2、6aug、7dim；创作/伴奏输入框下有可展开说明和可填入示例
- 按级数（2-5-1）或和弦名筛选 2,545 条乐句（BopLand 2,525 ＋ GuitarSet 20），支持跨调与来源筛选
- 浏览器按和声生成 6 类原创吉他乐句，支持默认六线谱／整页实音高五线谱切换、试听、本机收藏和 MIDI 导出
- Lead 可独立选择跟随整体、直八、Swing、Shuffle、Pocket 或 Laid-back 律动，并可加入双音点缀或当前和弦内的 Voicing
- 原创乐句默认自动安排音符密度：问答繁简互补、动机由简发展、句尾留白；也可选稀疏／适中／密集／繁密，并让每轮和声按种子随机改变密度
- 每次播放按 4 轮和声展开 Lead：可固定重复、按种子随机切换乐句写法，或指定 4 轮顺序（默认问答、动机、留白、留白）；停播时可逐轮查看谱面
- 温暖的真实拱面吉他采样、独立节奏吉他、鼓与电贝斯采样，并按风格提供合成键盘、Synth Bass 与原创电子鼓；伴奏律动和配器可按乐段随机变化
- 鼓、键盘、节奏吉他分别选择演奏风格并在整轮收尾加入 fill；键盘/节奏吉他支持 None
- 音色与音量一处控制；节奏吉他有暖净音、亮净音、厚过载、干净短奏、空间延音 5 种处理；Lead 在这 5 种吉他音色外另有爵士琴颈、Blues 边缘破音、歌唱延音、大钢琴和经逐音音量补偿的小提琴，共 10 种
- 伴奏与 Lead 使用可复现的轻微时间、力度和可定音声部音高偏差，并加入分轨声像、房间发送与更自然的尾音；这些处理改善 Studio 感，但不能替代实体设备上的真人听感验收
- Bass 新增「P 风格 · 厚实指弹」真实电贝斯采样：8 个音区、每音区 2 次独立录音，按需下载约 1.37 MB；保留原有 3 种 Bass 音色
- 创作与伴奏播放中换音色、风格、密度、乐句或 BPM，资源准备好后在下一个安全小节线生效；连续修改以最后选择为准，失败保留当前音乐并可重试
- 乐句示范音频、波形与 A/B 循环，换句恢复原速；伴奏可点选小节、变速和单节循环
- 本地记录课程完成状态
- 原生 Android 应用，支持 Android 8.0 及以上

## Android 构建

```powershell
./gradlew.bat assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 网站

正式网页：https://rexrockya.github.io/tuner/

`docs/` 是 GitHub Pages 的完整静态前端（调音、教学、分类乐谱、节拍器、Jam）。`website/` 是可选 Worker 实现，不要用其构建结果覆盖 `docs/`。

乐谱维护及前端测试：

```powershell
npm run build:scores
npm test
```

产品范围见 [PRD.md](PRD.md)，维护与发布见 [HANDOFF.md](HANDOFF.md)。目前无网页图片上传/自动识谱服务；家人可直接提交谱图附件进行异步转录。

可选 Worker 本地开发：

```powershell
cd website
npm install
npm run dev
```

## 隐私

麦克风音频仅在设备本地实时分析，不录音、不上传。

## 手机现场响度表

在原站点选择「工具 → 响度表」，允许使用麦克风。默认节目响度采用 ITU-R BS.1770-5 / EBU R128 的单声道/立体声算法，显示 M、S、累计 I、LRA 和真峰值 dBTP，可暂停/继续累计。频谱与最近 120 秒响度使用轻量曲线。切换“现场声级”支持 A/C/Z（A/C 为频域近似）、Fast/Slow、累计 Leq、SEL、最大响应值、Z 采样峰值、近似三分之一倍频程频谱和 CSV 导出。
未校准显示 dBFS；与参考声级计对照校准后才显示估算 dB SPL。校准仅对本次输入会话有效。
页面转入后台或输入中断时停止采集并保留结果。浏览器未必能关闭手机全部音频处理，且内置麦克风可能在演出声压下失真；不能替代专业声级计，也不能仅凭频谱判断场地传递频响。

电脑端可选麦克风设备，或通过浏览器共享选择器采集标签页/系统音轨；输出音频支持 LUFS / dBTP 与数字电平，不能做 SPL 校准。手机端按浏览器能力显示「手机输出」，不支持时禁用并说明原因，不会自动改用麦克风。调音与节拍也统一位于工具页。


网页版调音器采用音高环空闲界面，不再显示粗白条。可播放 A4 标准音并切换 440 / 441 Hz；手动进入“声音时间轴”后采集生活中的单音，显示音高轨迹和音名。时间轴不自动启动、不会录音，支持暂停画面和清空。

新音源为 Karoryfer Shinyguitar 的 CC0 采样；新增乐句来自 GuitarSet v1.1.0（CC BY 4.0），谱面按原始演奏标注生成并非人工认证转录。详见资源目录中的许可与来源记录。本轮验证与设备边界见 [音乐工具验收](notes/music-tools-validation-2026-09-08.md)。

新版伴奏风格、音色和五线谱维护与验证见 [组合练习验收](notes/ensemble-validation-2026-09-08.md)，本轮 Lead 律动、复音织体、4 轮变化与 Studio 化处理见 [演奏变化验收](notes/performance-variation-validation-2026-09-09.md)。多种鼓/Bass/吉他音色是现有真实录音的处理变体；新增 3 种 Lead 吉他音色也复用同一套 CC0 Shinyguitar 采样，并非新增录音。钢琴和小提琴复用乐谱音源。五线谱使用实际音高；Swing 等律动按直写谱显示、按所选律动播放。
